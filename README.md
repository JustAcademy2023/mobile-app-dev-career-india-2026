# Mobile App Development Career Opportunities in India 2026

A single-file, fully responsive landing page built around one topic: what it takes to become a mobile app developer in India in 2026. It walks visitors through the four hiring tracks (Flutter, Android, iOS, React Native), a three-step career roadmap, and a short reading list — all pulled from JustAcademy's Pune course and blog pages.

**Live preview:** open `index.html` directly in a browser, or enable GitHub Pages (Settings → Pages → deploy from `main` / root) to get a shareable URL.

## What's inside

- **Hero section** — a floating phone illustration with the four tech stacks orbiting it, plus a scroll-progress bar at the top of the page.
- **Stat strip** — three quick numbers framing why 2026 matters for mobile hiring in India.
- **Course tracks** — four clickable cards (Flutter, Android, iOS, React Native), each linking straight to its JustAcademy course page.
- **Career roadmap** — a three-step sequence: learn the stack, build a portfolio, get hired.
- **Reading list** — three JustAcademy blog links styled as a scannable list.
- **Footer** — quick links to every course and blog post repeated for easy access.

## Tech

Plain HTML, CSS, and a few lines of vanilla JavaScript (for the scroll-progress bar). No build step, no dependencies beyond two Google Fonts (`Space Grotesk` for headings, `Inter` for body text). Works as a static file anywhere — GitHub Pages, Netlify, Vercel, or a plain web server.

## Customizing

- Colors and spacing are defined as CSS custom properties at the top of the `<style>` block in `index.html` — change the values in `:root` to re-theme the page.
- Course and blog cards are plain `<a>` blocks — duplicate one and edit the text/link to add more.
